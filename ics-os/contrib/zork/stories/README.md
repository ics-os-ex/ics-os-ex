# Open story files (Z-machine)

This folder contains openly licensed or freely redistributable Z-machine story files downloaded from the IF Archive.

## Contents and licenses
- cluedo.z5 — Public domain (per IF Archive listing).
- Figaro.zblorb — GPL v3 (per IFWiki).
- bookvol.z5 — Freeware (per IFWiki).

## Sources
- https://www.ifarchive.org/if-archive/games/zcode/cluedo.z5
- https://www.ifarchive.org/if-archive/games/zcode/Figaro.zblorb
- https://www.ifarchive.org/if-archive/games/zcode/bookvol.z5

## Notes
- Some story files are Blorb containers (e.g., .zblorb). Ensure the interpreter supports Blorb when using those files.
- Verify licenses if you plan to redistribute beyond this repository.
